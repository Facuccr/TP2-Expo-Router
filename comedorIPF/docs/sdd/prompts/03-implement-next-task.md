# Prompt 03 — Implementar la próxima tarea

Leé:

- `AGENTS.md`
- `docs/sdd/spec.md`
- `docs/sdd/plan.md`
- `docs/sdd/tasks.md`
- `docs/sdd/acceptance.md`

Identificá la primera tarea pendiente `[ ]` que esté desbloqueada.

Reglas:


2. No implementar tareas futuras.
3. No cambiar la especificación salvo que descubras una contradicción real; en ese caso detenerte y documentarla.
4. Mantener el árbol de rutas definido.
5. No crear dependencias nuevas salvo necesidad explícita.
6. Si necesitás una dependencia Expo/React Native, instalarla solamente con `npx expo install`.
7. Ejecutar las verificaciones de esa tarea.
8. Corregir los errores relacionados con la tarea.
9. Revisar que no se haya creado una ruta accidental por colocar un componente dentro de `src/app`.
10. Marcar la tarea `[x]` solo si los criterios pasan.

Al finalizar informar:


- archivos creados/modificados;
- verificaciones ejecutadas;
- resultado;
- próxima tarea recomendada.

No continúes automáticamente con la próxima tarea.
