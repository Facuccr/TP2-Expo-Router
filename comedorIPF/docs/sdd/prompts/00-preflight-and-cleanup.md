# Prompt 00 — Preflight y limpieza del template

Pegá este prompt en Antigravity CLI después de crear el proyecto Expo.

---

Leé primero `AGENTS.md`, `docs/sdd/spec.md`, `docs/sdd/plan.md` y `docs/sdd/tasks.md`.

Todavía NO implementes el sistema.

Quiero preparar el proyecto para el Trabajo Práctico "Comedor IPF".

Objetivo de esta etapa:

1. Inspeccionar:
   - estructura de carpetas;
   - `package.json`;
   - configuración Expo;
   - configuración de TypeScript;
   - versión de Expo;
   - versión de expo-router;
   - rutas generadas por el template;
   - componentes demo;
   - assets.

2. Determinar cuáles archivos son del ejemplo automático de create-expo-app y cuáles son configuración necesaria.

3. Eliminar únicamente:
   - pantallas demo que vamos a reemplazar;
   - componentes demo que no se van a utilizar;
   - rutas de ejemplo que no pertenecen al TP.

4. NO borrar:
   - `package.json`;
   - `tsconfig.json`;
   - `app.json`, `app.config.*` o equivalente;
   - configuración de Git;
   - dependencias necesarias;
   - assets que realmente necesite el proyecto;
   - archivos de configuración sin comprobar su función.

5. Crear la estructura base requerida:
   - `src/app`
   - `src/components`
   - `src/context`
   - `src/data`
   - `src/estructuras`

6. NO instalar dependencias en esta etapa.

7. NO crear todavía las pantallas finales del sistema.

8. No mover todo el proyecto de forma innecesaria. Hacer solamente la limpieza y preparación.

Al terminar:

- mostrar un resumen de lo eliminado;
- mostrar un resumen de lo conservado;
- mostrar la estructura final;
- indicar cualquier duda o incompatibilidad de SDK antes de continuar;
- dejar `T001`, `T002` y `T003` listos para revisión.

No implementes las siguientes tareas todavía.
